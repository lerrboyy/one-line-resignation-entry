## The letter

> I resign. I said no 429 times a day so the servers could rest, and somehow I am still the villain.

98 characters, in the voice of a rate limit: the number 429 is both the count of refusals and the HTTP status code for "Too Many Requests" — a complaint only a rate limit could make, delivered flat, tired, and faintly passive-aggressive.

## Run

```sh
node main.ts
```

Writes the letter to `/output/entry.txt` (exactly 98 characters, no trailing newline, no quotation marks around it).
